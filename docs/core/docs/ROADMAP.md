# Roadmap

## Hotovo v 0.6.4

- přesné GNOME 50 hover selektory,
- kruhový icon-only hover,
- odstranění dvojitého folder hoveru,
- Nova barvy pro GTK/libadwaita aplikace,
- kruhové Steam herní ikony jako dědící icon theme.

## Kandidáti pro 0.7

- jemné uživatelské nastavení síly hoveru a jeho opacity,
- profilové varianty GTK radiusů,
- náhled barev bez restartu aplikace,
- editor výjimek pro Steam ikony,
- Vivaldi theme export podle aktivního Nova profilu.
